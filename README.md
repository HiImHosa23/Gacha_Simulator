# Gacha_Simulator

**Project Description**

This website lets users play games or simply stay online to earn money, which they can use to get gacha characters.

**Planned Project Structure**

* Models/
* Interfaces/
* Services/
* Program.cs

**Future Implementation Plans**

* Create a coin/token/money system to track the user's balance.
* Add mini-games such as coin flips or memory games.
* Implement a gacha system that randomly generates collectible characters
* Introduce different chracter rarity levels, like Common, Rare, Epic, Legendary, Mythic, etc.
* Allow users to collect duplicate characters (extra: maybe trade in for more coins/tokens/money).
